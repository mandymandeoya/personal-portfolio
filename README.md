# Anabelle Mandeoya | Portfolio Website

Personal portfolio of Anabelle Mandeoya, a BSIT student at ICCT Colleges. The home section has a full-height photo on the left and a pink tulip background on the right, with an icon-based navigation bar.

## Technologies used

HTML5, CSS3 (Grid, Flexbox, gradients, animations), JavaScript, Google Fonts (Poppins, Inter Tight, Cookie)

## Main features

- Responsive layout for laptop, tablet, and phone
- Icon navigation bar with hover labels and a mobile menu
- Animated role text, scroll animations, and a contact form that opens Gmail
- Separate pages: Home, About Me, Skills, Projects, Education & Achievements, Contact, each with the same navbar, footer, and back-to-top button
- Six live projects linked from the Projects section

## Pages

`index.html` (Home), `about.html`, `skills.html`, `projects.html`, `education.html`, `contact.html`. They share `style.css` and `script.js`.

## Run locally

Open `index.html` in a browser. No build step is needed.
